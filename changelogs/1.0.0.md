# BMP Quests 1.0.0

- Add conditional chapter images with quest visibility, availability, completion and ALL/ANY rules.
- Extend native image properties, quest selection and context menus.
- Add server-validated bulk text, rewards, dependency, appearance and visibility editing.
- Preserve quest locales and reward translations; integrate batches with FTB Undo/Redo.
- Add English and Russian interface translations and guides.
- Provide separate Fabric and NeoForge builds, unit tests and opt-in game-server integration checks.
- Reject bulk edits that would produce empty quest titles; provide clear single-line title and subtitle fields.
- Validate title replacement, translation preservation and Undo for selections of 100 quests.
- Build both loaders in GitHub Actions and publish complete versioned releases with checksums.

See [verification coverage](https://github.com/BMProjects-Development/BMP-Quests/blob/v1.0.0/docs/testing.md) for tested scenarios and remaining manual compatibility checks.
