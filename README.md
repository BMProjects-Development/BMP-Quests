# BMP Quests

BMP Quests expands the FTB Quests editor with conditional chapter images and bulk quest editing. It uses the original FTB interface, quest picker, reward editors and Undo/Redo history.

Install the matching Fabric or NeoForge JAR on **the server and every client**, alongside FTB Quests and its dependencies. Download builds from [Releases](https://github.com/BMProjects-Development/BMP-Quests/releases).
