# Руководство BMP Quests

[Главная](../README.md) · [English](en_us.md) · [Проверки](testing.md)

## Установка

Установите JAR для нужного загрузчика на сервер и все клиенты, вместе с FTB Quests и его обычными зависимостями. Существующие книги сохраняют исходное поведение изображений, пока вы не настроите новые условия. Поддерживаемая версия FTB Quests указана в метаданных мода.

## Условная видимость изображений

Включите режим редактирования FTB Quests, нажмите правой кнопкой на изображение, откройте его свойства и раздел **Видимость**.

| Режим | Когда видно изображение |
| --- | --- |
| Всегда видно | Исходное поведение изображения FTB Quests |
| Следовать видимости квеста | Связанный квест проходит штатную проверку видимости |
| Квест доступен | Команда может начать квест или уже выполнила его |
| Квест выполнен | Команда завершила квест |
| Несколько условий | Выполнены все условия или хотя бы одно |

Чтобы рамка скрытого квеста появлялась вместе с ним, выберите **Следовать видимости квеста**, нажмите **Связанный квест** и укажите квест в стандартном окне выбора. Сохраните свойства изображения.

Для иллюстрации, зависящей от двух этапов прохождения, выберите **Несколько условий**, откройте список **Условия** и добавьте две записи. У каждой записи свой квест и способ проверки. Выключенное **ANY (ИЛИ) вместо ALL (И)** означает, что нужны все условия; включённое — достаточно одного. Пустой список скрывает изображение.

Если связанный квест удалён, условие считается невыполненным, а в подсказке изображения в редакторе появляется предупреждение. Ссылка сохраняется: удаление квеста не делает картинку внезапно общедоступной. В режиме редактирования скрытые картинки доступны и отображаются полупрозрачно. В обычном режиме они не рисуются и не реагируют на нажатия. Прогресс команды поступает с сервера, изменения учитываются без повторного открытия книги.

Для быстрой привязки выделите квест с Ctrl, затем откройте меню изображения и выберите **Следовать видимости выделенного квеста**. Для нескольких картинок выделите их с Ctrl и выберите **Изменить выделенные изображения**. Команда **Очистить условия изображения** возвращает исходное поведение и запрашивает подтверждение.

Штатные свойства изображения «только для редакторов» и зависимость от выполнения квеста продолжают действовать вместе с условиями BMP.

## Массовое редактирование квестов

Выделите несколько квестов средствами FTB Quests: Ctrl-нажатиями, рамкой выделения или Ctrl+A. Нажмите правой кнопкой на квест и выберите **Массовое редактирование**. Заголовок показывает количество квестов и текущую локаль редактирования. Лимит — 256 квестов за одну операцию.

Параметры сгруппированы в разделы Основные, Текст, Награды, Зависимости и Видимость. Если исходные значения отличаются, поле **Текущее значение** показывает **Разные значения**. Новые значения редактируются отдельно. Включайте **Изменить этот параметр** только для нужных полей: остальные не затрагиваются.

Например, для префикса `[Глава 2] ` откройте Текст → Название, включите параметр, выберите Добавить в начало и введите текст. Для нового абзаца используйте Текст → Описание → Добавить строку / абзац: откроется оригинальный многострочный редактор. Поиск и замена работают с точным текстом, без регулярных выражений. Изменяется только текущая локаль, остальные переводы сохраняются.

Названия и подзаголовки вводятся в обычное текстовое поле, введённое значение сразу видно в окне. Одного включения параметра «Название» недостаточно: заполните **Новое название / текст операции**, затем применяйте изменения. Если хотя бы одно название получилось бы пустым или состояло только из пробелов, весь пакет отклоняется.

Для наград и зависимостей нужно выбрать операцию. **Настроить добавляемую награду** открывает штатный выбор типа и редактор награды FTB Quests. Копирование заменяет набор наград в целевых квестах, пропускает выбранный квест-источник и создаёт независимые ID наград. Удаление по типу затрагивает только указанный тип. Автополучение использует существующее свойство наград.

Зависимости можно добавлять, удалять по одной или очищать. Сервер проверяет итоговый граф, включая ссылки через главы и задачи. Зависимость от самого себя и циклы отклоняют весь запрос до внесения изменений.

Нажмите **Применить**, чтобы отправить все выбранные операции, или **Отмена**, чтобы отказаться от черновика. Замена текста, очистка зависимостей, удаление и замена наград требуют подтверждения. Штатные Undo/Redo отменяют и повторяют весь пакет одним действием. История общая для книги, как в FTB Quests.

## Хранение и перенос сборки

Условия находятся в данных каждого изображения под ключом `bmpquests_visibility`, внутри обычных файлов глав. Текст хранится в отдельных языковых файлах FTB Quests. Переносите всю квестовую книгу вместе с каталогом `lang`. Отдельной базы данных аддона нет.
