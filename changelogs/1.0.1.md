# BMP Quests 1.0.1

- Add the BMP Quests icon to the Fabric and NeoForge mod lists.
- Accept FTB Quests versions from the current minimum upward, without an upper version limit.
- Publish selected tested builds to GitHub and CurseForge only when explicitly requested with a `release` command; ordinary commits only build and verify.
- Support releasing all builds, a loader, a Minecraft version, or one version/loader combination, with a configurable build matrix for future ports.
- Keep unselected release files intact, and include version-specific notes and required dependencies on CurseForge.
